SmartServe AI

An intelligent virtual assistant for restaurants that captures late-night table reservations and answers guest questions 24/7. It keeps conversations natural and friendly, automatically boosts sales by suggesting chef specials from the menu, and sends instant booking notifications directly to the manager's phone for a quick, one-tap approval.

smart-serve-ai.com

Tech

  • State Machine Architecture: Backed by a strict, 3,900-line server-authoritative state machine that safely processes and structuralizes conversational data instead of letting the LLM talk directly to the database.
  • Proactive Revenue Generation: Implements smart, context-aware menu upselling with built-in safeguards to cap recommendations and prevent chat fatigue.
  • Production-Grade Security: Equipped with active DB-backed rate limiting to protect OpenAI API budgets, along with HMAC-signed webhooks, secure HttpOnly cookie sessions, and transcript-validated cancellation tokens.
  • Real-Time Data Sync: Leverages Pusher API infrastructure alongside Telegram Bot APIs to maintain an instant, zero-latency feedback loop between guests, managers, and the admin dashboard.
